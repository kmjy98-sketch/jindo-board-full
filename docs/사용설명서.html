1이게 뭔가요?

법학 공부는 "챕터"가 아니라 논점(쟁점) 단위로 돌아갑니다.

이 보드는 논점 하나하나의 진행도를 클릭으로 관리합니다. 그리고 그 기록을 클라우드가 아니라 여러분 폴더 안의 마크다운 파일에 직접 씁니다.

셀 클릭 → 논점 .md 파일
frontmatter 갱신 → 옵시디언·다른 도구도
같은 파일을 읽음

✔ 왜 이 방식인가

  • 내 데이터는 내 것 — 계정 없음, 서버 없음. 파일은 내 디스크에만
  • 브라우저를 바꿔도 이어짐 — 기록이 브라우저가 아니라 파일에 있으니까
  • 기존 도구와 함께 — 옵시디언 볼트 안에 그대로 두고 Bases로도 열람

⚠ 한 가지 조건

크롬 또는 엣지에서 여세요. 이 두 브라우저에만 있는 기능(File System Access API)으로 폴더에 직접 씁니다. 파이어폭스·사파리, 그리고 일부 앱 내장 브라우저는 로컬 쓰기를 지원하지 않습니다.

23분 만에 시작

처음이라면 동봉된 sample-vault 폴더로 바로 체험할 수 있습니다.

1
다운로드 · 압축 해제
GitHub에서 ZIP을 받아 원하는 위치에 풉니다.
2
진도_board.html 더블클릭
크롬·엣지가 기본 브라우저가 아니면, 파일 우클릭 → "연결 프로그램" → 크롬/엣지를 고릅니다.
3
[볼트 연결] 클릭 → 공부 폴더 선택 → "허용"
처음엔 sample-vault 폴더를 고르면 예시 논점이 바로 뜹니다. 내 걸 쓰려면 다음 장의 폴더 구조대로 만든 폴더를 고르세요.
4
셀을 클릭하면 회독 +1
Shift-클릭 또는 우클릭 = −1. 클릭하는 순간 해당 논점 .md 파일에 저장됩니다. 저장 버튼 없음.

⚠ "읽기 전용"이라고 뜨면

상단 [쓰기 허용] 버튼을 누르고, 브라우저가 물으면 "변경 허용"을 선택하세요. 그래도 안 되면 앱 내장 브라우저가 아니라 일반 크롬·엣지 창에서 열었는지 확인하세요.

3폴더 구조와 논점 파일

규칙은 딱 두 가지: 폴더 위치와 파일 맨 위 frontmatter.

폴더 구조

연결하는 폴더 안에 sync/위키/{과목}/ 구조만 있으면 됩니다. 목표·로그 폴더는 자동으로 생깁니다.

내볼트/
└─ sync/
   └─ 위키/
      ├─ 민법/                  ← 과목 폴더
      │   ├─ 채권자대위권.md
      │   └─ …
      ├─ 형법총론/
      └─ …

인식 과목명(고정): 민법 · 형법총론 · 형법각론 · 헌법 · 민사소송법 · 민사집행법 · 행정법 · 형사소송법 · 상법 · 선택법

논점 파일 (파일 1개 = 논점 1개)

파일명이 곧 보드 셀 이름입니다. 본문은 자유(비워도 OK).

---
type: 쟁점          # 이게 있는 파일만 보드에 뜸
과목: 민법
대분류: 채권법        # 보드의 가로줄 묶음
논점: 01            # 묶음 안 정렬 번호
회독: 0             # ↓ 4개는 클릭으로 자동 갱신
선택: 0
사례: 0
기록: 0
약점: false
진도: 미착수
---

# 채권자대위권
(본문 자유)

4보드 사용법

기록 모드를 고르고, 목표 기간을 정하고, 클릭합니다.

진도 보드 v9
당장: 1학년 여름 기간 목표 전체 회독선택사례기록
책임재산 보전
채권자대위권 2회채권자취소권 1회
법정채권
부당이득 1회 사2불법행위
기능방법
기록 모드상단 [회독][선택][사례][기록] 중 선택 후 셀 클릭 = +1
4종 트랙회독 / 선택형 / 사례형 / 기록형을 각각 따로 카운트
탭당장 목표(지금 하는 기간) · 기간 목표(12기간) · 전체
백업[JSON 내보내기]로 파일 저장

🎨 색으로 보는 진행도

회독 횟수가 늘수록 셀 색이 연한 초록 → 진한 초록으로 짙어집니다. 한눈에 "덜 본 논점(흰색·연한 색)"이 드러나 어디를 더 봐야 할지 바로 보입니다.

5기간 목표 — "지금 하는 것"에 집중

1년을 학기·방학 12기간으로 나누고, 지금 하는 기간을 [당장 목표]로 고정합니다.

1-1 학기→ 1학년 여름→ 1-2 학기→ 1학년 겨울→ …
1
[기간 목표] 탭에서 기간을 고릅니다
예: "1학년 여름"
2
[단원 편집]을 켜고 이번 기간에 할 논점을 담습니다
셀 하나씩, 또는 과목 헤더·중분류 라벨을 클릭하면 그 전체를 한 번에 담습니다.
3
[현재로 지정]을 누릅니다
그 기간이 ★로 표시되고, [당장 목표] 탭이 그 기간을 가리킵니다. 부팅하면 바로 이 화면이 뜹니다.

📐 학기는 중간·기말까지 쪼개기

학기 기간을 고르면 [학기 전체 | 중간 | 기말] 범위 토글이 나옵니다. 중간고사 범위, 기말고사 범위를 따로 담을 수 있고, 중간·기말에 담은 논점은 자동으로 "학기 전체"에도 포함됩니다. 시험일도 학기별·중간/기말별로 나눠 관리됩니다.

6스터디 공유 · 서버 모드 · FAQ

👥 스터디원에게 논점 목록 나눠주기

정리된 논점 목록이 있으면, 진도 기록·본문을 뺀 뼈대만 복제해 배포용 볼트를 만듭니다:

python tools/make_skeleton.py "내볼트경로" "출력폴더"

🖥️ (선택) 서버 모드

볼트 직결로 충분하면 필요 없습니다. 원하면 파이썬 로컬 서버로도 같은 보드를 엽니다(포트 8770).

python server/board_server_v2.py    # 파이썬 3.10+
