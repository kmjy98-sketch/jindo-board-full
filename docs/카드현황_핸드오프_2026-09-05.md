**제안 패치** (라이브 볼트 `.agent/skills/daily-drill/scripts/build_session.py`에 적용. 이 저장소의 사본은 스냅샷이라 여기서 고쳐도 볼트에 반영되지 않는다):

```python
def _원문_to_card_paths(원문):
    if not 원문:
        return []
    m = _PAGE_RE.search(원문)
    if not m:
        return []
    base = os.path.basename(원문[:m.end()])       # 다중 경로·괄호 주석 대비: 첫 파일명만
    mb = _PAGE_RE.search(base)
    book_part = base[:mb.start()]
    page_part = mb.group(0)
    book_glob = book_part.replace("_llamaparse", "*")   # 카드 파일명의 llamaparse 유무 허용
    hits = glob.glob(os.path.join(CARDS, f"{book_glob}{page_part}*_v37.md"))
    if not hits:
        hits = glob.glob(os.path.join(CARDS, f"{book_glob}*_v37.md"))[:3]
    return sorted(hits)
```

여기에 `CARD_KEYWORDS["행정법"]`에 `"행정법강해"`, `["민법"]`에 `"컴민법"`, `["민사소송법"]`에 `"민소사례"`를 추가하면 과목단위 폴백에서 빠지는 77개 파일(행정법강해 47·컴민법 14·민소사례 7·포섭트리거 5·사례풀이순서 4)이 줄어든다. 포섭트리거·사례풀이순서는 과목명이 파일명에 있으므로 키워드 `포섭트리거_{과목}`·`사례풀이순서_{과목}`로 등록하면 된다. 행정법강해는 페이지 범위가 원문과 어긋나므로 논점단위 연결까지 하려면 **페이지 구간 겹침 기준 매칭**(원문 p241-270 ⊂ 카드 p239-275)이 추가로 필요하다.
