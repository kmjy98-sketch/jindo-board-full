# 종속형식·간접정범 — 법전협 2018(2)모의 제2문 [사례 38]

## 문제 (사실관계, 소스 원문)

甲·乙이 중학생 丙(13세, A의 아들)에게 A의 돈을 훔치면 비트코인을 사서 돈을 벌어주겠다고 하였다. 丙은 범죄임을 알면서도 A의 돈 50만 원을 절취하여 甲·乙에게 건넸다.

**甲·乙의 죄책은?**

## 풀이순서 (골격)

1. **[丙의 지위]** 13세 = 형사미성년자(§9) → 책임무능력자
2. **[제한적 종속형식에 따른 甲·乙의 죄책]** 정범 행위가 구성요건·위법성만 갖추면 공범 성립 → 丙이 책임무능력자라도 독자적 판단 하에 행위 → 甲·乙 = **절도죄의 교사범**(의사지배 없으므로 간접정범 아님) + 본범의 교사범·방조범도 장물죄 가능 → **장물취득죄의 공동정범** → 절도교사죄 + 장물취득죄 실체적 경합
3. **[극단적 종속형식에 따른 甲·乙의 죄책]** 정범 행위가 책임까지 구비해야 공범 성립 → 丙의 행위는 책임조각 → 교사범 불성립 → §34①"처벌되지 아니하는 자" 이용 → **간접정범** → 본범의 정범은 장물죄 불성립(불가벌적 사후행위) → 甲·乙 = **절도죄의 간접정범**만 성립

## 포섭격자

| 요건 | 사실 (원문) | 제한적 종속형식 | 극단적 종속형식 |
|---|---|---|---|
| 丙의 형사책임 | 13세(형사미성년, §9) | 책임 불요 → 교사 가능 | 책임 필요 → 교사 불가 |
| 甲·乙의 丙 이용 | A의 돈 훔치면 비트코인 사주겠다 | 절도교사죄 | 절도죄의 간접정범 |
| 장물 죄책 | 丙(본범)이 甲·乙에게 절취금 교부 | 교사범·방조범도 장물죄 가능 → 장물취득죄 공동정범 | 본범의 정범은 불가벌적 사후행위 → 장물죄 불성립 |
| 죄수 | — | 절도교사죄 + 장물취득죄 실체적 경합 | 절도죄의 간접정범만 |

## 모범답안 (채점 전용, 소스 원문)

### 사실관계

甲·乙이 중학생 丙(13세, A의 아들)에게 A의 돈을 훔치면 비트코인을 사서 돈을 벌어주겠다고 하였다. 丙은 범죄임을 알면서도 A의 돈 50만 원을 절취하여 甲·乙에게 건넸다.

### 1. 제한적 종속형식에 따른 甲·乙의 죄책

**제한적 종속형식**: 정범 행위가 구성요건·위법성을 갖추면 공범이 성립한다는 입장이다.

丙이 13세(책임무능력자)로 독자적 판단 하에 행위하였으므로 → 甲·乙은 **절도죄의 교사범**이다(의사지배가 없으므로 간접정범이 아니다).

**장물취득죄(제362조 제1항)**: 본범의 교사범·방조범도 장물죄가 성립할 수 있으므로 → 甲·乙은 **장물취득죄의 공동정범**이다.

→ **절도교사죄 + 장물취득죄의 실체적 경합**.

### 2. 극단적 종속형식에 따른 甲·乙의 죄책

**극단적 종속형식**: 정범 행위가 책임까지 구비하여야 공범이 성립한다는 입장이다.

丙의 행위는 책임조각되므로 → 교사범이 불성립한다. **제34조 제1항 "처벌되지 아니하는 자"**를 이용한 것이 되어 → **간접정범**이 성립한다.

**장물취득죄**: 본범의 정범은 장물죄가 불성립한다(불가벌적 사후행위) → 甲·乙은 **절도죄의 간접정범**만 성립한다.

## 채점포인트·함정 (본 청크 핵심 정리, 소스 원문 반영)

- **종속형식 논거 양측 제시**: 제한적 종속형식 → 절도교사죄 + 장물취득죄(공동정범) 실체적 경합; 극단적 종속형식 → 절도죄의 간접정범만. 둘 다 논해야 고득점.
- **극단적 종속형식의 장물죄 불성립 근거**: "자기 소유물이 되어서"가 아니라 **본범의 정범은 장물죄가 불성립하는 불가벌적 사후행위 법리**가 근거다. 이 법리적 근거를 정확히 서술해야 한다(소스 원문 확인 결과 종전 노트의 "자기 소유물" 서술은 오류로 확인되어 삭제함).
- **제한적 종속형식에서는 장물취득죄가 오히려 성립**(교사범·방조범도 본범 아니므로 장물죄 주체가 될 수 있음) — 극단적 종속형식(간접정범 구성 시 불가벌적 사후행위)과 반대 결론임에 유의.
- **함정**: 13세 丙을 통한 교사 → "교사범" vs "간접정범"이 종속형식에 따라 갈린다. 13세가 14세 미만(형사미성년, §9)임을 반드시 명시.
