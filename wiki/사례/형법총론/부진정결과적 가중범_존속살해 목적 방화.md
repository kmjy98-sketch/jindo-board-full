## 문제

### 사실관계

甲은 평소 사이가 매우 좋지 않은 자신의 아버지 A를 죽여야겠다고 마음먹고, 후배 乙에게 A의 집에 불을 질러 A를 살해해 달라고 사주하였다. 이를 승낙한 乙은 A가 자고 있는 집에 휘발유를 뿌리고 불을 질렀으나 집 천장까지 불길이 붙자 놀라서 도망하였고, A는 소방대에 구조되어 다친 곳은 없었다.

### 설문

甲과 乙의 죄책은? (30점)

## 풀이순서

1. 乙의 죄책
   1-1. 현주건조물방화죄(§164①) 기수 여부 — 독립연소설로 기수
   1-2. 살인죄 미수 형태 — 중지미수vs장애미수 (자의성 절충설)
   1-3. 현주건조물방화치사상죄 미수 성립 여부 — 미수처벌규정 無 → 방화기수+살인미수 상상적 경합
2. 甲의 죄책
   2-1. 현주건조물방화교사죄
   2-2. 존속살해미수교사죄(§250②) — §33 단서 적용 (신분관계 형의 경중)
   2-3. 양죄 죄수: 상상적 경합
3. 결론

## 포섭격자

| 요건 | 사실 | 결론 |
|------|------|------|
| **乙 — 현주건조물방화죄(§164①) 기수** | | |
| ①현주건조물 | A가 자고 있는 집 (사람 현존) | 현주건조물 ○ |
| ②방화·독립연소(판례 독립연소설) | 집 천장까지 불길 → 독립 연소 상태 도달 | 기수 ○ |
| **乙 — 살인미수 형태** | | |
| 중지미수 자의성(절충설) | 집 천장까지 불길이 붙자 "놀라서" 도망 → 외부적 장애([[대판 1997.6.13, 97도957]]) | 자의성 × → 장애미수 |
| **현주건조물방화치사상죄 미수** | | |

| 죄수처리 | 방화기수(§164①) + 살인장애미수(§254, §250①) | 상상적 경합 |
| **甲 — 현주건조물방화교사죄** | | |
| 방화 결의 없는 乙에게 방화 결의 야기 | 乙에게 방화 사주·승낙 → 교사 성립 | 교사범 ○ |
| **甲 — 존속살해미수교사죄(§250②)** | | |
| 신분관계 형의 경중 — §33 단서 적용 | 甲은 A의 아들, 乙은 A와 무관 → 신분자가 비신분자 교사([[대판 1994.12.23, 93도1002]]) | §33 단서: 甲에게 존속살해죄 적용 |
| 미수 | 살인 미발생 | 존속살해미수교사죄 |
| **甲 죄수** | 방화교사+존속살해미수교사 = 1개 교사행위 | 상상적 경합 |

## 모범답안

(1) [乙의 죄책] (가) [현주건조물방화죄] ① 현주건조물방화죄의 기수 시기에 대해 독립연소설, 중요부분연소개시설, 효용상실설이 있고, 판례는 독립연소설의 입장이다. ② 乙이 A의 집에 불을 질러 집 천장까지 불길이 붙었으므로 A의 집은 독립하여 연소할 상태에 이르렀다. ③ 따라서 乙은 현주건조물방화기수죄(제164조 제1항)의 죄책을 진다. (나) [살인장애미수죄] ① 중지미수([[§26]])의 자의성에 대하여, 객관설, 주관설, 프랑크공식, 절충설 등이 있고, 판례는 절충설의 입장이다([[대판 1997.6.13, 97도957]]). 범행 당시 객관적 사정과 내부적 사정을 종합적으로 고려하는 절충설이 타당하다. ② 乙은 집 천장까지 불길이 붙자 놀라서 도망하였는데 이와 같은 사정은 일반 사회통념상 범죄 완수에 장애가 되는 사정에 해당하므로([[대판 1997.6.13, 97도957]]), 乙의 중지에 자의성이 인정되지 않는다. ③ 따라서 乙은 살인장애미수죄의 죄책을 진다(제254조, 제250조 제1항, 제25조). (다) [현주건조물방화치사죄의 미수범] 현주건조물방화치사죄(제164조 제2항)는 부진정 결과적 가중범이지만 미수범 처벌규정이 없으므로, 乙에게 현주건조물방화치사죄의 미수범은 성립하지 않는다. (라) [죄수관계] 乙은 현주건조물방화죄 및 살인미수죄의 상상적 경합범의 죄책을 진다. (2) [甲의 죄책] (가) [현주건조물방화교사죄] ① 교사는 범죄를 결의하지 않은 피교사자에게 '특정범죄를 결의'하게 하는 것을 말한다(제31조 제1항). ② 甲은 방화의 결의가 없는 乙에게 현주건조물방화를 결의하게 하였으므로 현주건조물방화교사죄의 죄책을 진다. (나) [존속살해미수교사죄] ① 신분관계로 인하여 형의 경중이 있는 경우에 신분이 있는 자가 신분이 없는 자를 교사하여 죄를 범하게 한 때에는 [[§33]] 단서가 제31조 제1항에 우선하여 적용된다([[대판 1994.12.23, 93도1002]]). ② 甲은 乙에게 甲의 존속 A를 살해할 것을 교사하였으므로 존속살해미수교사죄(제250조 제2항)의 죄책을 진다. (3) [결론] ① 甲은 현주건조물방화교사죄 및 존속살해미수교사죄의 상상적 경합범의 죄책을 진다. ② 乙은 현주건조물방화죄 및 살인미수죄의 상상적 경합범의 죄책을 진다.

## 채점포인트·함정

- 핵심 쟁점: 부진정결과적 가중범의 미수범 처벌규정 부존재 → 방화기수+살인미수 상상적 경합 처리
- 乙의 중지미수 자의성 판단 — 절충설·판례 적용하여 장애미수로 결론
- 甲의 §33 단서 적용 — 신분자(甲)가 비신분자(乙)를 교사한 경우 판례 인용 필수
- 함정: 현주건조물방화치사죄 중지미수를 긍정하는 실수 주의 (미수처벌규정 無)
- 함정: 乙의 중지미수 인정 실수 (놀라서 도망 = 외부적 장애)
