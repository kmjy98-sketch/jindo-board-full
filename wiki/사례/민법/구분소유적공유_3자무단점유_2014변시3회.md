# 구분소유적 공유 — 제3자 무단점유 시 일방 구분소유권자의 전체 인도청구 (2014년 제3회 변시)

## 문제

甲은 乙에게서 P시에 소재하는 1필의 X토지 중 일부를 위치와 면적을 특정하여 매수했으나 필요가 생기면 추후 분할하기로 하고 분할등기를 하지 않은 채 X토지 전체 면적에 대한 甲의 매수 부분의 면적 비율에 상응하는 지분소유권이전등기를 甲 명의로 경료하고 甲과 乙은 각자 소유하게 될 토지의 경계선을 확정하였다. X토지 옆에서 공장을 운영하던 丙은 X토지가 상당 기간 방치되어 있는 것을 보고 甲과 乙의 동의를 받지 아니한 채 甲이 소유하는 토지 부분에는 천막시설을, 乙이 소유하는 토지 부분에는 컨테이너로 만든 임시사무실을 丙의 비용으로 신축, 설치하여 사용하고 있었다. 이를 알게 된 甲은 천막시설과 컨테이너를 철거하여 X토지 전체를 인도하라고 요구하였고, 丙이 이에 불응하자 甲은 甲 자신만이 원고가 되어 丙을 상대로 X토지 전체의 인도를 구하는 소송을 제기하였다(천막 및 컨테이너의 각 철거를 구하는 청구는 위 소송의 청구취지에 포함되어 있지 않다). 위 소송에서 丙은 'X토지 전체가 甲과 乙의 공유인데 乙은 현재 X토지의 인도를 요구하지 않고 있다.'는 취지의 주장을 하고 있다.

**甲의 丙에 대한 청구가 인용될 수 있는지와 그 근거를 서술하시오. (20점)**

## 풀이순서

1. 甲과 乙의 X토지 소유형태: 구분소유적 공유(1필 공유지분 등기 + 특정부분 배타적 점유 약정)
2. 구분소유적 공유의 법률관계
   2-1. 대내적: 각자 특정구분부분에 배타적 사용·수익권 + 타방 침해 시 소유권에 기한 방해배제 가능(대판 2012.4.26. 2010다6611)
   2-2. 대외적: 1필지 전체에 관하여 공유관계 성립 → 제3자 방해 시 전체 토지에 관하여 공유물의 보존행위로서 배제 청구 가능(대판 1994.2.8. 93다42986)
3. 甲이 丙을 상대로 X토지 전체 인도를 구할 수 있는지
   3-1. 丙은 甲·乙 동의 없이 점유 → 무단점유자
   3-2. 대외적으로 공유관계이므로 일방 구분소유권자가 공유물 보존행위로서 전체 인도 청구 가능
4. 천막·컨테이너 철거와 인도 청구의 관계
   4-1. 철거 없이 인도 가능 여부: 별개 소송물이지만 인도청구 자체는 문제 없음
5. 결론: 甲의 청구 인용 가능

## 모범답안

**Ⅰ. 甲과 乙의 X토지 소유형태**

수인이 하나의 부동산의 특정부분을 각자가 배타적으로 점유·소유하기로 하면서 등기는 공유지분등기 ∴ 구분소유적 공유

**Ⅱ. 구분소유적 공유의 법률관계**

[대내적 관계] 각자가 특정구분된 부분에 대하여 배타적인 사용·수익권 → ㉠ 다른 구분공유자가 배타적 부분을 침해하면 소유권에 기하여 방해배제 청구 ○(대판 2012.4.26, 2010다6611), ㉡ 구분소유자 각자는 '자신의 특정구분부분'을 단독으로 처분하고 그에 해당하는 공유지분등기 자유로이 이전 ○(대판 2009.10.15, 2007다83632)

[대외적 관계] 1필지 전체에 관하여 '공유관계' 성립 → 제3자의 방해행위가 있으면 전체 토지에 관하여 '공유물의 보존행위'로서 배제 청구 ○(대판 1994.2.8, 93다42986)

**Ⅲ. 甲이 丙을 상대로 X토지 전체의 인도를 구할 수 있는지 여부**

丙은 천막시설 등을 설치하면서 甲과 乙의 동의를 받지 않았으므로 X토지의 무단점유자 → 제3자 방해행위시 일방 구분소유권자는 전체 토지에 관하여 '공유물의 보존행위'로서 배제 청구 가능 ∴ 甲은 乙의 구분소유부분 포함하여 X토지 전체 인도 청구 ○

토지인도를 실제 실행하기 위해서는 천막 등의 철거를 구해야 하나 양자는 별개소송물이므로 천막 등의 철거를 구하지 않고 X토지의 전체 인도를 구하는 것은 문제 ×

**Ⅳ. 결 론**

甲의 丙에 대한 청구는 인용 가능

## 채점포인트·함정

- 구분소유적 공유의 대외적 관계: 제3자에 대해서는 일반 공유 규정 적용 → 보존행위로 전체 인도 청구 가능.
- 乙이 청구하지 않더라도: 보존행위는 단독으로 가능하므로 乙의 의사와 무관.
- 천막·컨테이너 미철거 문제: 별개 소송물이므로 인도청구 자체는 인용 가능. 단 실제 집행 시 문제될 수 있음.
