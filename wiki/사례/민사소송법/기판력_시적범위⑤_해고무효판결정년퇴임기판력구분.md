# 기판력 시적 범위⑤ — 해고무효판결 후 정년퇴임, 기판력 구분

## 문제

甲은 Z회사에서 근무하던 중 2010. 4. 1. 해고를 당하여 2010. 5. 1. Z회사를 상대로 해고무효확인 및 해고기간 동안 월급상당의 손해배상을 구하는 소(이하 '전소')를 제기하였다. 2015. 4. 5. 변론이 종결되었고 甲은 승소판결을 받아 확정되었다. Z회사는 판결에서 명한 대로 2010. 4. 1.부터 2015. 6. 5.까지 월 500만 원씩 계산한 돈을 지급하였다. 그런데 Z회사는 나중에 甲이 소송계속 중이던 2014. 3. 31. 정년퇴임한 사실을 알게 되었다. 그리하여 Z회사는 甲을 상대로 Z에게 지급한 돈 중에서 2014. 4. 1.부터 2015. 6. 5.까지 지급한 것은 부당이득임을 이유로 반환을 구하는 소(이하 '후소')를 제기하였다. 甲이 2014. 3. 31. 정년퇴임한 사실은 객관적 증거에 의해 증명되었다.

이 경우 후소법원은 Z회사의 청구에 대해 어떠한 판결을 선고해야 하는가? (10점)

## 풀이순서

1. 전소 확정판결의 기판력이 후소에도 미치는지 — 모순관계 해당 여부
2. 기판력의 시적 범위 및 차단효
3. 사안검토: 전소 표준시(2015. 4. 5.)를 기준으로 기간 분리
   - 2014. 4. 1. ~ 2015. 4. 5. 기간 지급금: 기판력 위반(표준시 이전 사유 = 차단효)
   - 2015. 4. 6. ~ 2015. 6. 5. 기간 지급금: 기판력 미생긴 부분 → 별도 판단 가능
4. 결론

## 모범답안

**I 논점정리**

㉠ 전소 확정판결의 기판력이 후소에도 미치는지 여부, ㉡ 기판력의 시적 범위(차단효)에 관하여 살펴보아야 한다.

**II 전소 확정판결의 기판력이 후소에도 미치는지 여부**

기판력은 ㉠ 전소와 후소의 소송물이 동일한 경우, ㉡ 전소의 소송물이 후소의 선결문제인 경우, ㉢ 전소와 후소가 모순관계인 경우에 한하여 작용한다. 본건의 경우 전소 소송물은 해고무효를 전제로 '甲이 Z회사에 대해 2010. 4. 1.부터 2015. 6. 5. 기간 동안 월 500만 원으로 계산한 손해배상청구권을 갖는다'는 것이고, 후소 소송물은 甲이 소송계속 도중인 2014. 3. 31. 정년퇴임했음을 이유로 '2014. 4. 1.부터 2015. 6. 5. 기간 동안에는 손해배상청구권이 없으므로 당해 기간 동안 받은 손해배상금은 부당이득으로 반환되어야 한다'는 것이어서 전소의 소송물과 후소의 소송물은 모순관계에 있어 전소 확정판결의 기판력은 후소에도 미친다.

**III 기판력의 시적 범위 및 차단효**

기판력의 표준시는 '사실심 변론종결'로서 기판력은 원칙적으로 '표준시 당시의 권리관계의 존부'에 대해서 생긴다. 이러한 기판력의 시적범위로 인해 '차단효(실권효)'가 생기게 된다. 즉 동일한 소송물에 대한 후소에서 전소 변론종결 이전에 존재하고 있던 공격방어방법을 주장하여 전소 확정판결에서 판단된 법률관계의 존부와 모순되는 판단을 구하는 것은 전소 확정판결의 기판력에 반하는 것이고, 전소에서 당사자가 그 공격방어방법을 알지 못하여 주장하지 못하였는지 나아가 그와 같이 알지 못한 데 과실이 있는지는 묻지 아니한다(대판 2014.3.27. 2011다49981).

**IV 사안검토**

① 전소의 변론종결일은 2015. 4. 5.이다. 후소에서 乙회사가 ㉠ 甲이 2014. 3. 31. 정년퇴임을 했다는 주장을 새로이 내세우면서 그 시점 이후에는 양자간에 고용관계가 존재할 수 없기 때문에 2014. 4. 1.부터 전소 사실심변론종결시인 2015. 4. 5.까지 지급한 손해배상금을 부당이득으로서 반환해야 한다고 주장하는 것은 전소 확정판결의 기판력에 위반되어 허용되지 않는다.

② 그러나 ㉡ 전소법원은 사실심 변론종결시 이후에 甲-乙 사이에 고용관계가 존재하는지에 대해서는 전혀 판단한 바 없기 때문에 2015. 4. 6.부터 2015. 6. 5. 기간 동안 지급된 손해배상금에 대해서는 후소법원이 새로이 제출된 주장과 증거를 토대로 독자적으로 판단할 수 있다. 甲이 2014. 3. 31. 정년퇴임한 사실은 객관적인 증거에 의해 증명된 이상 후소법원은 2015. 4. 6.부터 2015. 6. 5. 기간 동안 지급된 손해배상금은 부당이득에 해당하므로 甲은 乙에게 이를 반환해야 한다고 판단할 수 있다.

③ 결론적으로 후소법원은 ㉠ 2014. 4. 1. - 2015. 4. 5. 사이에 지급된 손해배상금을 부당이득으로 반환을 구하는 부분은 청구기각판결을, ㉡ 2015. 4. 6. - 2015. 6. 5. 사이에 지급된 손해배상금을 부당이득으로 반환을 구하는 부분은 청구인용판결을 선고해야 한다.

## 채점포인트·함정

- 핵심: 전소 표준시(2015. 4. 5.)를 기준으로 이전/이후 기간 분리
- 정년퇴임(2014. 3. 31.) = 표준시 이전에 발생한 사유 → 차단효로 표준시까지 기간은 기판력에 의해 차단
- 표준시 이후 기간(2015. 4. 6. ~ 2015. 6. 5.): 전소에서 판단 안 됨 → 후소에서 새로 심리 가능
- 관련 판례(98다9908): 해고무효·임금판결에서 변론종결 이후 부분은 단지 장래 권리관계를 예측한 것 → 변론종결 이전 정년퇴직 사유로 변론종결 이후 부분을 다투는 것은 기판력에 저촉 아님
