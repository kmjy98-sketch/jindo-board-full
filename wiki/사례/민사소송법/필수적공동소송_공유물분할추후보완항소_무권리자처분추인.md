# 필수적공동소송② — 공유물분할, 추후보완항소, 무권리자처분추인 후 피고적격

## 문제

A, B, C는 X토지를 공유하고 있다(공유지분 각 1/3). A, B, C는 X토지 분할에 관하여 협의를 하였으나 합의가 이루어지지 않았고, 이에 A는 B, C를 상대로 하여 공유물분할청구를 구하는 소를 제기하였다(이하 '이 사건 본소'). 이 사건 본소 1심법원은 피고들에 대한 송달을 공시송달로 진행한 다음, A가 X토지를 단독 소유하되 B, C에게 가액배상금을 지급하는 내용의 공유물분할판결을 선고하였다. A는 X토지를 D에게 3억 원에 매도한 후 형식적으로 확정된 1심 판결을 기초로 B, C에 대한 배상금(1심 판결의 변론종결 무렵 B, C 지분의 가액인 각 8,000만 원)을 공탁하는 한편 B, C의 지분에 관하여 자신 앞으로 소유권이전등기를 마친 후 D에게 매매를 원인으로 하여 소유권이전등기를 마쳐 주었다.

B, C는 A가 자신들을 상대로 이 사건 본소를 제기하여 위 내용의 판결이 선고되어 확정된 사실을 나중에 알게 되었고 적법하게 추후보완 항소를 제기하였다. B, C는 이 사건 본소 항소심에서 "A가 X토지를 이미 처분하였으므로 이 사건 본소는 더 이상 유지될 수 없다"고 다투는 한편 반소를 제기하여 A가 D로부터 받은 매매대금 중 B, C 지분 상당액에 관하여 부당이득으로 반환할 것을 청구하였다(반소요건을 갖추었다고 전제하고 이자는 고려하지 말 것).

위 제시 사실관계는 모두 이 사건 본소 항소심에서 주장·증명되었다고 할 경우 이 사건 본소 항소심 법원은 본소와 반소에 대해 어떤 판결을 선고해야 하는가? (15점)

## 풀이순서

1. 반소 제기의 실체법적 의미
   - B, C가 "A가 이미 처분하였으므로 본소는 유지될 수 없다"고 다투면서 동시에 '부당이득반환 반소' 제기
   - 이는 B, C가 자신들 지분에 대한 A의 처분행위를 **묵시적으로 추인**한 것(실체법상 추인)
   - 추인 → B, C는 X토지 공유자 지위 상실

2. 본소에서의 피고적격 문제
   - 공유물분할소송 = 분할청구자 원고 + 다른 공유자 전부 공동피고 = 고유필수적 공동소송
   - 공유자가 지분을 이전하면 승계참가·소송인수 방식으로 새 당사자가 되어야 함(민소법 제81·82조, 대판 2014.1.29. 2013다78556)
   - B, C는 추인으로 공유자 지위 상실 → 피고적격 소멸
   - 항소심 = 사실심 변론종결시 기준 → D(새 소유자)가 당사자가 되지 않은 상태

3. 본소 판결 형태
   - 항소심: 1심 판결 취소 + 본소 각하(피고적격 없음)
   - 근거: 대판 2022.6.30. 2020다210686

4. 반소 판결
   - B, C의 반소 = A가 D로부터 받은 매매대금 중 B, C 지분 상당액 부당이득 반환청구
   - 무권리자(A)가 B, C의 지분을 D에게 처분 → B, C 추인 → A의 처분행위 소급 유효
   - A는 B, C 지분에 해당하는 매매대금(3억 원 × 2/3 = 2억 원)을 부당이득으로 B, C에게 반환
   - 반소 인용(B, C 각 1억원씩)

## 포섭격자

| 요건 | 사실관계 | 평가 | 증명책임 |
|---|---|---|---|
| 묵시적 추인 | 처분 인정 + 부당이득 반소 제기 | B, C = 지분 처분 묵시 추인 | 직권조사 |
| 피고적격 소멸 | B, C 공유자 지위 상실 | 피고적격 없음 → 본소 각하 | 직권조사 |
| 본소 판결형태 | 1심 공시송달 진행 | 1심 취소 + 본소 각하(대판 2020다210686) | 직권조사 |
| 부당이득 반소 | A가 매매대금 3억원 중 B,C 지분분 각 1억원 취득(공탁한 각 8천만원은 지분가액일 뿐 무관) | B, C 각 1억원 부당이득 인용 | 원고(B, C — 반소청구자) |

## 모범답안

### Ⅰ. 논점정리

㉠ '본소'와 관련해서는 공유물분할소송의 당사자적격 구비 여부 검토, ㉡ '반소'와 관련해서는 무권리자처분행위가 권리자의 추인으로 인해 소급적으로 유효해진 경우 권리자의 무권리자에 대한 부당이득반환청구권 문제를 검토한다.

### Ⅱ. 본소에 대한 판결

[무권리자처분행위 추인] A가 승소확정판결(가격분할)에 기하여 B, C의 지분에 관하여 자신 앞으로 소유권이전등기를 마친 후 X토지를 D에게 매각하여 이전등기까지 마친 상태에서, B, C가 추후보완항소를 하면서 'A가 X토지를 이미 처분하였으므로 본소는 유지될 수 없다'고 하면서 반소로 'A가 D로부터 받은 매매대금 중 B, C 지분 상당액에 관하여 부당이득으로 반환할 것을 청구'한 것은 실체법적 차원에서 B, C 보유 각 지분에 관한 A의 처분행위를 묵시적으로 추인한 것이다. 따라서 B, C는 X토지의 공유자 지위를 상실한다.

[피고적격 문제] 공유물분할청구소송은 분할을 청구하는 공유자가 원고가 되어 다른 공유자 전부를 공동피고로 삼아야 하는 고유필수적 공동소송으로서, 소송계속 중 원심 변론종결일 전에 공유자의 지분이 이전된 경우 원심 변론종결 시까지 민소법 제81조에서 정한 승계참가나 제82조에서 정한 소송인수 등의 방식으로 그 일부 지분권을 이전받은 자가 소송당사자가 되어야 하고, 그렇지 못할 경우 소송 전부가 부적법하다(대판 2014.1.29. 2013다78556). 이 사건 추후보완 항소심의 경우에도 '사실심변론종결시'를 기준으로 각 보유지분의 처분행위를 추인한 B, C의 당사자적격이 상실된 상태이므로, 항소심 법원은 '1심판결을 취소하고, 이 사건 본소를 각하'하는 내용의 판결을 선고해야 한다(대판 2022.6.30. 2020다210686).

### III. 반소에 대한 판결

[판례] 무권리자에 의한 처분행위를 권리자가 추인한 경우 권리자는 무권리자에 대하여 '무권리자가 처분행위로 인하여 얻은 이득의 반환'을 청구할 수 있다(대판 2001.11.9. 2001다44291).

[사안검토] A가 B, C에게 반환할 부당이득금은 '매매대금 중 B, C 지분에 해당하는 부분' 즉 각 1억 원씩이다. A의 B, C에 대한 보상가액(공탁한 금액인 각 8,000만 원)은 B, C의 지분 처분행위로 얻은 이득이 아니고, X토지 분할을 전제로 1심 판결의 변론종결 무렵 B, C 지분의 가액일 뿐이므로 부당이득반환에 대한 반소를 심리함에 있어서 위 공탁금액을 고려할 필요가 없다(대판 2022.6.30. 2020다210686).

### IV. 결 론

항소심 법원은 ㉠ '본소'에 대해서는 '1심판결을 취소하고 이 사건 본소를 각하한다'는 내용의 판결을, ㉡ '반소'에 대해서는 'A는 B, C에 대해 각각 1억 원의 지급을 명해야 한다'는 내용의 판결을 선고해야 한다.

## 채점포인트·함정

- **핵심①**: 묵시적 추인 → 지분처분 유효 → 공유자 지위 상실 → 피고적격 소멸 → 본소 각하
- **핵심②**: 반소 = 부당이득반환청구(대판 2001.11.9. 2001다44291, 무권리자 처분 추인시 이득반환청구권) → A가 받은 매매대금 중 B, C 지분분(각 1억 원) 반환
- **핵심③**: A가 이미 공탁한 보상가액(각 8,000만 원)은 지분 처분으로 얻은 이득이 아니라 분할 전제 지분가액일 뿐이므로 반소 부당이득 산정에서 공제·고려 대상이 아님(대판 2022.6.30. 2020다210686) — 이 부분을 놓치면 반소 인용액 계산이 틀림
- **함정**: "B, C가 항소 = 취소 + 분할 다시 심리"라고 쓰면 피고적격 논점 누락
- **함정**: "본소 기각"이라고 쓰면 오답 — 피고적격 없으면 각하(소송요건 흠결)
- **함정**: 공탁된 8,000만 원을 반소 인용액에서 공제하면 오답 — 공탁금은 부당이득과 무관
- 고유필수적 공동소송에서 지분이전 → 당사자 교체 필요 법리 핵심
- 대판 2022.6.30. 2020다210686, 대판 2001.11.9. 2001다44291, 대판 2014.1.29. 2013다78556 참조
