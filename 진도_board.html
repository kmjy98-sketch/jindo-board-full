사용법접기 ▾
  • 기록 모드 — [회독][선택][사례][기록]. 셀 클릭 = 현재 모드 +1, Shift·우클릭 = −1. 셀에 N회 선N 사N 기N.
  • 탭 = [당장 목표](현재 기간, 부팅 기본) / [기간](학기·방학 12기간) / [전체]. 모두 같은 데이터를 거르는 렌즈(데이터 안 바뀜).
  • 기간 구조 — 1년 = 학기·방학 교차 12기간(1-1 → 1학년 여름 → 1-2 → 1학년 겨울 → …). [기간]에서 고른 뒤 [현재로 지정] = 당장 목표. 학기 기간은 [학기 전체|중간|기말] 하위범위 지원(중간·기말에 담으면 학기 전체에 자동 포함).
  • 단원 편집 — [단원 편집] 켜고 셀 클릭으로 담기. 큰 단위 담기: 편집 중 과목 헤더/중분류 라벨 클릭 = 그 전체 일괄. [누적] = 전 기간 합산 보기(편집 불가).
  • 저장·백업 — 자동 저장. [JSON 내보내기] → 6.진도관리/백업/. 상태 [저장 환경 보기].
  • 열기 방식 — 더블클릭(크롬·엣지)이면 최초 1회 [볼트 연결]로 법학볼트 폴더 지정 → 이후 클릭이 논점 frontmatter에 직접 저장(서버·bat 불필요). 서버(bat)로 열어도 동일하게 저장됨.
