### [풀이순서] 강도상해·치상죄, 강도살인·치사죄 — 채무면탈 목적 살인

앞: 채무면탈 목적으로 채권자를 살해한 경우 강도살인죄([[§338]]) 성립 여부 풀이순서?

뒤:
1. 강도살인죄 성립 요건 확인: 선행 강도죄 성립 필요
2. 강도죄 요건: {{c1::불법이득의사}} + 재산상 이익의 취득(이익이 피해자 측에서 범인 앞으로 {{c2::사실상 이전}})
3. 분기점 — 상속인의 채권 확인 가능 여부
   - 확인 방법 있음 → {{c3::일시적 추급 면탈}}에 불과 → 이전 부정 → 강도죄 불성립 → 강도살인죄 불성립
   - 확인 방법 없음 → 이전 인정 → 강도죄 성립 → 강도살인죄 성립 가능
4. 사안 포섭 → 결론
