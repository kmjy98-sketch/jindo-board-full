## 토지관할① — 보통재판적·특별재판적·변론관할·이송신청권 (p.3)

1. 피고 주소지(보통재판적) 확인 → 관할법원 특정
2. 답변서 제출로 변론관할 성립 여부 → 대결 1980.9.26. 80마403: 부정(답변서만으로 부족)
3. 관할위반 확인 → 직권이송 가능성
4. 당사자 이송신청권 존부 → 93마524: 없음(직권발동 촉구만)
5. 결론: 관할위반 → 직권 적법관할법원으로 이송

## 토지관할② — 관련재판적·관할위반과 이송신청권 (p.5)

1. 제25조 제2항 관련재판적 적용 범위 판단
   - 객관적 병합(주관적 병합 불가)
2. 각 피고별 관련재판적 충족 여부
   - 丙: O / 丁: X
3. 관할위반 피고(丁)에 대한 처리: 직권이송
4. 당사자 이송신청권: 93마524 = 없음

## 토지관할③ — 이송신청에 대한 법원 조치·이송결정 불복 (p.7)

**[설문1] 관할위반 없음 → 이송신청 각하**
1. 전속적 합의관할 존부 확인
2. 관할위반 여부 판단
3. 관할위반 없음 → 이송신청기각결정
4. 기각결정에 대한 불복 수단: 즉시항고 불가 → 각하

**[설문2] 이송결정 불복**
1. 이송결정의 위법 여부(관할위반 없음에도 이송)
2. 불복 수단: 즉시항고(제39조)
3. 이송결정 취소 가능

## 사물관할 — 단독판사사건 청구취지확장·합의부 이송 (p.10)

1. 소제기 당시 소송물 가액 → 단독/합의부 사물관할 판단
2. 관할항정의 원칙(제35조) 확인
3. 청구취지 확장으로 합의부 관할로 변경 시 예외 해당 여부
   - 단독 → 합의부: 이송 가능(단, 피고 변론관할 성립 여부 확인)
4. 피고가 변론관할 성립: 이송결정 부적법

## 합의관할① — 합의관할의 종류와 승계 (채권승계인) (p.12)

## 관할이송의 구속력 — 심급관할위반 이송 (p.19)

1. 집행법원 항고장각하명령에 대한 불복의 성질: 최초 항고(94마1961)

   - 하급심: 미침

## 법관제척① — 재심소송에서 이전심급 재판관여 (p.21)

1. 제41조 제5호 '불복사건의 이전심급 재판에 관여' 해당 여부
2. '이전심급'의 의미(대판 2000재다87): 원재판 ≠ 이전심급
3. 재심의 대상 = 원재판(동일심급의 특수절차)
4. 결론: 제척사유 미해당

## 법관제척② — 배우자 소송대리인·파기환송 전원심 관여 (p.22)

**[A] 소송대리인과 배우자 관계**
1. 제41조 제1호·제2호 해당 여부 → 소송대리인과 배우자 = 미해당

**[B] 파기환송 전원심판결 관여**
1. 파기환송 전후 동일 심급 여부
2. 제41조 제5호 = '다른 심급'에서 관여한 경우에만 제척
3. 같은 심급이면 제척 미해당(심급 달리하지 않음)
4. 단, 제436조 제3항 특칙: 종전 원심판결에 관여한 법관은 파기환송심 관여 불가

## 당사자확정① — 사자 피고·당사자표시정정 (p.24)

**[설문 나] 사자 피고 판결 효력**
1. 사자 피고 판결 = 당연무효(2000다33775)
2. 상속인의 항소 = 부적법 각하

## 당사자확정② — 피고사망 간과 판결·항소심 표시정정 (p.26)

1. 소장부본 송달 전 피고 사망 → 사자 상대 소제기 문제
2. 사자 피고 판결 = 당연무효(2000다33775)
3. 원고의 항소 = 무효
4. 항소심 표시정정 신청 = 무효(적법 항소 전제 필요)
5. 구별: 소각하 후 항소+항소심 표시정정은 가능(74다834)

## 당사자확정③ — 상속포기 모르고 제소·피고경정과 소멸시효 중단 (p.28)

1. 실질적 피고 = 실제 상속인(丁)(2009다49964)
2. 형식상 피고경정 = 표시정정 실질 → 처음부터 丁 상대 소제기로 취급
3. 소멸시효 완성일(2017. 12. 31.) vs 소제기일(2017. 10. 1.) → 소제기 시 중단
4. 丁의 소멸시효 항변 이유 없음

## 당사자확정④ — 항소심 임의적 당사자변경 오판·상고 적법성 (p.30)

3. 항소심 오판: 원고경정으로 보아 甲교회를 원고로 취급
4. 진정한 원고에 대해 항소심 판결 미선고 → 상고대상 없음
5. 결론: 상고 각하. 정상경로 = 원심법원 변론기일지정신청

## 당사자능력① — 비법인사단 대표자의 총유물보존 소제기 원고적격 (p.32)

**단계::포섭 주제::공시송달·추후보완기산점·소송대리인수령**

**[설문 2]** 乙이 직접 판결문 수령한 경우

2. 치유: 항소심에서 수계신청 + 추인 → 하자 치유(대판 2016.4.29. 2014다210449)

3. 기판력 효력: 후소법원 = 전소와 모순 판단 불가(모순금지설)
4. 채권양도 통지 없음 이유 기각 = 전소 기판력 저촉 → 불허
5. 결론: 후소법원은 甲 청구 기각 불가
