## 토지관할① — 보통재판적·특별재판적·변론관할·이송신청권 (p.3)

1. 피고 주소지(보통재판적) 확인 → 관할법원 특정
2. 답변서 제출로 변론관할 성립 여부 → 대결 1980.9.26. 80마403: 부정(답변서만으로 부족)
3. 관할위반 확인 → 직권이송 가능성
4. 당사자 이송신청권 존부 → 93마524: 없음(직권발동 촉구만)
5. 결론: 관할위반 → 직권 적법관할법원으로 이송

## 토지관할② — 관련재판적·관할위반과 이송신청권 (p.5)

1. 제25조 제2항 관련재판적 적용 범위 판단
   - 객관적 병합(주관적 병합 불가)
2. 각 피고별 관련재판적 충족 여부
   - 병: O / 정: X
3. 관할위반 피고(정)에 대한 처리: 직권이송
4. 당사자 이송신청권: 93마524 = 없음

---

## 토지관할③ — 이송신청에 대한 법원 조치·이송결정 불복 (p.7)

**[설문1] 관할위반 없음 → 이송신청 각하**
1. 전속적 합의관할 존부 확인
2. 관할위반 여부 판단
3. 관할위반 없음 → 이송신청기각결정
4. 기각결정에 대한 불복 수단: 즉시항고 불가 → 각하

**[설문2] 이송결정 불복**
1. 이송결정의 위법 여부(관할위반 없음에도 이송)
2. 불복 수단: 즉시항고(제39조)
3. 이송결정 취소 가능

---

## 사물관할 — 단독판사사건 청구취지확장·합의부 이송 (p.10)

1. 소제기 당시 소송물 가액 → 단독/합의부 사물관할 판단
2. 관할항정의 원칙(제35조) 확인
3. 청구취지 확장으로 합의부 관할로 변경 시 예외 해당 여부
   - 단독 → 합의부: 이송 가능(단, 피고 변론관할 성립 여부 확인)
4. 피고가 변론관할 성립: 이송결정 부적법

## 합의관할① — 합의관할의 종류와 승계 (채권승계인) (p.12)

## 관할이송의 구속력 — 심급관할위반 이송 (p.19)

1. 집행법원 항고장각하명령에 대한 불복의 성질: 최초 항고(94마1961)
2. 항고법원의 대법원 이송결정 = 심급관할 위반 이송
3. 이송결정 구속력 범위
   - 상급심(대법원): 미치지 않음(심급 이익 박탈·사실심리 불가)
   - 하급심: 미침
4. 대법원의 조치: 적법하게 재이송

## 법관제척① — 재심소송에서 이전심급 재판관여 (p.21)

1. 제41조 제5호 '불복사건의 이전심급 재판에 관여' 해당 여부
2. '이전심급'의 의미(대판 2000재다87): 원재판 ≠ 이전심급
3. 재심의 대상 = 원재판(동일심급의 특수절차)
4. 결론: 제척사유 미해당

---

## 법관제척② — 배우자 소송대리인·파기환송 전원심 관여 (p.22)

**[A] 소송대리인과 배우자 관계**
1. 제41조 제1호·제2호 해당 여부 → 소송대리인과 배우자 = 미해당

**[B] 파기환송 전원심판결 관여**
1. 파기환송 전후 동일 심급 여부
2. 제41조 제5호 = '다른 심급'에서 관여한 경우에만 제척
3. 같은 심급이면 제척 미해당(심급 달리하지 않음)
4. 단, 제436조 제3항 특칙: 종전 원심판결에 관여한 법관은 파기환송심 관여 불가

## 당사자확정① — 사자 피고·당사자표시정정 (p.24)

**[설문 가] 동일성 인정 시 표시정정**
1. 실질적 표시설로 당사자 확정
2. 실질적 피고 = H → 동일성 O → 당사자표시정정 허용

**[설문 나] 사자 피고 판결 효력**
1. 사자 피고 판결 = 당연무효(2000다33775)
2. 상속인의 항소 = 부적법 각하

---

## 당사자확정② — 피고사망 간과 판결·항소심 표시정정 (p.26)

1. 소장부본 송달 전 피고 사망 → 사자 상대 소제기 문제
2. 사자 피고 판결 = 당연무효(2000다33775)
3. 원고의 항소 = 무효
4. 항소심 표시정정 신청 = 무효(적법 항소 전제 필요)
5. 구별: 소각하 후 항소+항소심 표시정정은 가능(74다834)

---

## 당사자확정③ — 상속포기 모르고 제소·피고경정과 소멸시효 중단 (p.28)

1. 실질적 피고 = 실제 상속인(정)(2009다49964)
2. 형식상 피고경정 = 표시정정 실질 → 처음부터 정 상대 소제기로 취급
3. 소멸시효 완성일(2017. 12. 31.) vs 소제기일(2017. 10. 1.) → 소제기 시 중단
4. 정의 소멸시효 항변 이유 없음

---

## 당사자확정④ — 항소심 임의적 당사자변경 오판·상고 적법성 (p.30)

1. 원고 확정: 실질적 표시설 → 선정당사자 홍길동(교인 100명)
2. 1심 원고표시정정 = 적법
3. 항소심 오판: 원고경정으로 보아 갑교회를 원고로 취급
4. 진정한 원고에 대해 항소심 판결 미선고 → 상고대상 없음
5. 결론: 상고 각하. 정상경로 = 원심법원 변론기일지정신청

## 당사자능력① — 비법인사단 대표자의 총유물보존 소제기 원고적격 (p.32)

3. 대표자·일부 종중원 = 총유물 보존행위 소제기에서도 원고 불가(2004다44971 전합)
4. 결론: 소각하

## 당사자능력② — 종중 대표권 성격·성립요건·소집통지결여 총회결의 (p.33)

**[문제2] 병 주장이 사실인 경우**

2. 일부 종원 소집통지 결여 총회결의 = 무효(91다43862)
3. 대표권 무효 → 소각하

## 당사자능력③ — 비법인사단 총유물 소제기·정관사원총회결의 흠결 (p.35)

## 소송대리인③ — 변호사 소송대리권 존속시기·파기환송 시 대리권 부활 (p.58)

### [풀이순서] 관할이송_구속력_이송후심리범위 (p709-710)

**단계::포섭 주제::공시송달·추후보완기산점·소송대리인수령**

**[설문 1]** 소송대리인 A변호사가 판결문 수령 후 을에게 전달 증거 없는 경우

**[설문 2]** 을이 직접 판결문 수령한 경우
1. 당사자가 직접 수령한 경우: 판결 있었던 사실 알았고 사회통념상 당연히 알아볼 특별한 사정
2. 직접 수령일(2024.4.5.)이 기산점 → 2주 이내 = 2024.4.19. 까지

**단계::포섭 주제::소제기전사망·소송대리권 존속·수계신청**

2. 수계 없이 판결 선고: 유효 → 실질적 원고 C에게 효력 미침
3. 불복 시: B에게 판결정본 송달 → 심급대리 종료 → 소송중단 → 1심법원에 **수계신청 후 항소**

1. 수계신청 없이 바로 변호사 D 선임 → 대리권 없는 소송행위 = 무효
2. 치유: 항소심에서 수계신청 + 추인 → 하자 치유(대판 2016.4.29. 2014다210449)

3. 기판력 효력: 후소법원 = 전소와 모순 판단 불가(모순금지설)
4. 채권양도 통지 없음 이유 기각 = 전소 기판력 저촉 → 불허
5. 결론: 후소법원은 갑 청구 기각 불가

### [풀이순서] 당사자적격①_말소등기청구소송피고적격_이행소피고적격

**단계::포섭 주제::당사자적격**

1. 논점정리: ① 말소등기청구소송에서의 피고적격, ② 이행청구소송에서의 피고적격이 주된 논점
2. 을을 상대로 병 앞으로 마쳐진 소유권이전등기의 말소등기를 구하는 청구의 적법성
   - 이행의 소에서는 원고의 주장 자체만으로 당사자적격이 인정되는 것이 원칙이나, '등기말소·말소회복등기 이행청구'의 경우 「등기의무자」를 피고로 하지 않으면 피고적격 없는 자를 상대로 한 부적법한 소로 각하(대판 1994.2.25. 93다39225, 대판 2009.10.15. 2006다43903 등)
   - 본건 '등기의무자'는 병(현재 등기명의인) → 을을 상대로 한 말소등기의 소는 피고적격 없는 자를 상대로 한 소로서 부적법
3. 을을 상대로 소유권이전등기를 구하는 청구의 적법성
   - 매매를 원인으로 하는 소유권이전등기청구소송 = 이행의 소 → 당사자적격은 원칙적으로 원고의 주장 그 자체로 결정
   - 원고적격 = 자기의 이행청구권을 주장하는 자, 피고적격 = 그로부터 이행의무자로 주장된 자
   - 본안심리 결과 권리·의무가 존재하지 않으면 청구기각판결을 선고해야 하며, 당사자적격 흠결을 이유로 소각하판결을 선고해서는 안 됨(대판 2005.10.7. 2003다44387)
   - 본건: 갑의 을에 대한 이전등기청구는 적법 — 을의 이중매매·이전등기 완료로 갑의 청구권이 이행불능이더라도 소각하가 아닌 본안판결(청구기각)을 선고해야 함
4. 결론: ①청구(을 상대 말소등기청구)는 피고적격 흠결로 부적법 각하, ②청구(을 상대 이전등기청구)는 적법(본안에서 이행불능이면 청구기각)

### [풀이순서] 당사자적격②_제3자소송담당

**단계::포섭 주제::당사자적격**

**사실관계 1**
1. 제3채무자에 대한 압류·추심명령과 채무자의 당사자적격
   - 압류·추심명령이 있으면 제3채무자에 대한 추심권한이 집행채권자에게 이전
   - C가 B를 상대로 채권압류·추심명령을 받은 상태에서 채무자 A가 B를 상대로 대여금청구의 소를 제기 → '원고적격 흠결'로 소각하(대판 2004.3.26. 2001다51510 등)
2. 압류·추심명령의 취하와 종전 채무자의 당사자적격 회복 문제
   - 제1심 변론종결 전 C가 압류·추심명령 신청을 취하하고 추심권을 포기 → 채무자(A)는 당사자적격 회복(대판 2010.11.25. 2010다64877)
   - 당사자적격은 소송요건으로서 '사실심변론종결시'를 기준으로 판단(대판(전합) 1977.5.24. 76다2304) → 제소 당시 흠결이 있었어도 판단시점에 흠결이 메워지면 소는 적법
3. 결론: C의 압류·추심신청 취하로 A의 원고적격 흠결이 메워짐 → A의 청구는 (B에 대한 1천만원 금전채권이 있으므로) 전부 인용

**사실관계 2**
4. 논점정리: 압류·전부명령이 있으면 피압류채권이 종전 채무자에서 전부채권자로 당연 이전되고 집행채권은 소멸 → 같은 피압류채권을 후순위로 양수받은 자는 존재하지 않는 채권을 양수받은 셈이어서 양수금청구권 없음 → 이런 허무의 채권 양수인이 제3채무자에게 양수금청구를 하면 원고적격 흠결로 소각하해야 하는지 문제됨
5. 이행청구의 소에서의 당사자적격 법리
   - 이행청구의 소에서 당사자적격은 원고가 주장하는 대로 인정하는 것이 원칙
   - 원고적격 = 자기에게 이행청구권이 있다고 주장하는 자, 피고적격 = 그 상대방이라고 주장된 자
   - 이행청구권이 나중에 인정되지 않아도 청구기각판결을 선고해야지 원고적격 흠결을 이유로 소각하해서는 안 됨
   - 이 법리는 선행 채권압류·전부명령으로 허무의 채권을 양수한 양수인의 양수금지급청구에도 그대로 적용
6. 결론: D의 압류·전부명령이 유효하여 C에 우선하더라도 C에게 원고적격은 인정됨 → 피고 B의 원고적격 흠결 주장(본안전 항변)은 배척되어야 하고, 법원은 본안심리에 들어가야 함(본안에서 C의 청구권이 인정되지 않으면 청구기각)

### [풀이순서] 변론주의보완_석명권한계_건물매수청구권 (송영곤 민사소송법 사례연습 2026 pp.105-106 (민소사례_llamaparse_p091-120))

**단계::포섭 주제::변론주의보완_석명권한계_건물매수청구권**

3. **사안 적용 — 임차인(을)에 대한 석명 여부**
   - 건물매수청구권 = 을의 독립된 공격방어방법(항변권)
   - 법원이 을로 하여금 건물매수청구권을 행사하도록 유도하는 것 = 변론주의 위반, 석명권 한계 일탈
   - **결론: 법원은 을에게 건물매수청구권의 행사 여부에 관하여 석명하여서는 안 된다**

4. **상기 예외 판례(94다34265)와의 구별**
   - 위 전합 판결은 임대인(원고·갑)에 대한 청구취지 석명에 관한 것
   - 본 사안은 임차인(피고·을)에 대한 항변 행사 유도 — 별개 문제

**단계::포섭 주제::보조참가인지위②_재판상자백_의제자백_참가인다툼_사망불중단**

   - 병이 제1 차용 및 제1 보증 사실 인정 → **재판상 자백** 성립(자백 구속력)

   - 병이 제2 보증에 대해 침묵 → **자백간주**(제150조 제1항)

   - **제2 보증 청구 기각**

3. 결론: 제1 보증 청구 **인용**, 제2 보증 청구 **기각**

   - 상소수권 없는 경우: 판결정본 소송대리인에게 송달된 때 소송대리권 소멸 → 소송절차 중단
2. 보조참가인의 사망이 소송절차를 중단시키는지
   - 보조참가인은 당사자가 아니므로, 보조참가인 사망으로 본소의 소송절차 **중단되지 아니함**(대판 1995.8.25. 94다27373)

### [풀이순서] 보조참가참가적효력①_효력범위_배제사유_변론주의 (민사사례연습1 p.953-955 (2012. 10. 모의))

**단계::포섭 주제::보조참가참가적효력①_효력범위_배제사유_변론주의**

**[설문 1 — 전부 승소판결 가능 여부]**

1. 참가적 효력 관련성 검토
   - 참가적 효력: 피참가인 패소 후 **참가인 상대의 소송**에서 피참가인에 대해 종전 판결 내용 부당 주장 불가(대판 1988.12.13. 86다카2289)
   - 본건: **참가인(을)이 피참가인의 상대방(갑)을 상대로 소 제기** → 참가적 효력 미적용
2. 기판력 관련성 검토
   - 기판력 제3자 효력: 변론종결 후 승계인·목적물 소지인·소송담당 권리귀속주체·소송탈퇴자에 한정
   - 을은 이 중 해당 없음 → 기판력 불적용
   - 기판력은 판결주문에만 미침(제216조 제1항) → 이유 중 판단에 기판력 불생

   - 계약해제 사실은 피고의 권리장애(권리소멸) 항변 → **피고 갑** 증명책임
   - 법원이 확신 없음 → 피고 불이익 → 매매계약 유효 존속 전제
4. 동시이행항변과 변론주의
   - 갑은 잔금 중 일부 미수령 → 실체법상 동시이행항변 가능
   - 그러나 동시이행항변권은 **주요사실(권리저지 항변)** → 변론주의 적용
   - 갑이 소송에서 주장하지 않으면 법원 고려 불가(증거자료 ≠ 소송자료)
   - 사안: 갑이 잔금 미수령 사실 변론에서 주장하지 않음 → 법원 동시이행항변 고려 불가
5. 결론: **을 전부 승소판결 가능**

**[설문 2 — B소송에서 참가적 효력과 배제사유]**

1. A소송 확정판결의 참가적 효력 존재 여부

### [풀이순서] 소주관적예비적병합①_피고추가신청적법성_판결형태 (민사사례연습1_llamaparse_p931-960 p.934-935 (2022년 제11회 변시))

**단계::포섭 주제::소주관적예비적병합①_피고추가신청적법성_판결형태**

1. 소의 주관적·예비적·추가적 병합 요건(민소법 제70조)
   - ① 법률상 양립할 수 없을 것, ② 공동소송 주관적 요건(§65)·객관적 요건(§253), ③ §68 준용으로 주관적 추가적 병합도 가능(대판 2015.6.11. 2014다232913), 시기는 제1심 변론종결시로 제한
   - '법률상 양립불가능'의 의미: 민소법 §70① 본문의 '공동소송인 가운데 일부에 대한 청구'를 '모든 청구'로 해석할 근거 없음 → 주위적 피고에 대한 주위적·예비적 청구 중 주위적 청구가 인용 안 될 경우 그와 양립불가능한 예비적 피고에 대한 청구를 인용해 달라는 취지의 결합도 가능(대판 2009.3.26. 2006다47677, 대판 2014.3.27. 2009다104960)

2. 사안의 법률상 양립불가능 판단
   - 병의 을에 대한 청구(무권대리 전제)는 병의 갑에 대한 주위적 청구(유권대리)에 대해서만 양립불가능, 예비적 청구(표현대리)와는 양립가능 → 예비적 피고 추가 가능

3. 판결형태
   - 주위적 피고에 대한 예비적 청구와 예비적 피고에 대한 청구가 서로 법률상 양립가능한 관계 → 양 청구를 병합하여 통상의 공동소송으로 심리·판단(대판 2006다47677, 대판 2009다104960)
   - 갑에 대한 주위적 청구(유권대리)는 대리권 불인정으로 기각, 예비적 청구(표현대리)는 요건 충족으로 인용
   - 표현대리 성립시 민법 제135조 책임 여부: 다수설은 부정(본인효과와 무권대리인 책임 선택적 인정은 공평 문제). 소수설은 긍정(표현대리 입증 곤란한 실무 현실 고려, 강용현 민법주해)
   - 예비적 피고 을에 대한 청구는 다수설에 따르면 기각(소수설에 따르면 인용)

4. 결론: ① 추가 신청 적법. ② 갑 주위적 청구 기각, 예비적 청구 인용; 을 청구 기각(다수설)

### [풀이순서] 소주관적예비적병합②_예비적병합항소심_주관적예비적항소불가분 (민사사례연습1_llamaparse_p931-960 p.936 (2019. 6. 모의) / p.937-938 (2017. 8. 모의))

**단계::포섭 주제::소주관적예비적병합②_예비적병합항소심_주관적예비적항소불가분**

**[사례7 — 입주자대표회의 예비적 피고 추가 적법성]**

1. 을의 피고적격 확인
   - 단체 내부 대표자선출결의 무효·부존재 확인의 소: 피고적격자 = **단체**, 결의로 선출된 대표자는 피고적격 없음
   - Z(동대표 개인)는 피고적격 없음 → 현재 소는 부적법
2. 입주자대표회의 당사자능력 확인
   - 입주자대표회의 = 동별세대수 비례 선출 동별대표자 구성 비법인사단(대판 2007.6.15. 2007다6307) → 대표자 있으면 당사자능력 인정(민소법 제52조)
3. 소의 주관적·예비적·추가적 병합 요건 검토
   - ① 법률상 양립불가능: 누가 피고적격인지에 따라 한쪽만 적법(대결 2007.6.26. 2007마515) → 충족
   - ② 공동소송의 주관적 요건(제65조)·객관적 요건(제253조)
   - ③ 제68조 준용으로 주관적 추가적 병합 가능, 제1심 변론종결시까지 제한(제70조 제1항)
4. 결론: 1심 변론종결 전까지 입주자대표회의를 예비적 피고로 추가 가능

**[사례8 — 항소심 판결형태]**

**I. 을의 청구에 대한 판결형태 (객관적 예비적 병합)**

1. 예비적 병합과 상소불가분원칙 확인
   - '상소불가분의 원칙'(확정차단·이심효는 불복신청 범위와 무관하게 원판결 전부에 발생) → 항소로 주위적 청구 포함 전체 이심(대판 1995.1.24. 94다29065)
   - 항소심 심판범위: 피고가 불복신청한 **예비적 청구를 인용한 1심판결의 당부에 한정**(원고 부대항소 없는 한 주위적 청구 심판불가, 대판 2002.12.26. 2002므852)
2. 1심법원이 기각한 주위적 청구가 이유 있다고 판단할 경우
   - 예비적 청구만 심판대상이라는 이유로 예비적 청구를 기각하면 피고에게 불합리하게 유리
   - 항소심은 주위적 청구를 심판할 수 없는 한계 + 피고만 항소한 경우 불이익변경금지원칙 적용 → 1심판결 취소·주위적 청구 인용도 불가
   - **항소기각판결**로 1심 유지(타당). 학설 중 '1심 예비적 청구 인용판결 취소·예비적 청구 기각판결' 견해(2022.10 법전협 모의고사 채점기준표)도 있으나 피고에게 부당하게 유리하여 부적절
3. 결론: 을에 대한 청구는 **항소기각**

**II. 병·정 청구에 대한 판결형태 (주관적·예비적 병합)**

1. 소의 주관적·예비적 병합 심리방식
   - 청구포기·인낙·화해·소취하 제외 필수적 공동소송 심판절차(민소법 제70조 제1항), 모든 공동소송인에 대해 판결(같은조 제2항), 일부만 판결·추가판결 불허(대판 2014.3.27. 2009다104960)
2. 상소불가분원칙·항소심 심판대상·불이익변경금지
   - 주관적·예비적 공동소송은 소송자료·진행의 통일 요구(제70조①, 제67조~69조) + 합일확정 판결 필요 → 어느 한 공동소송인의 상소로 다른 공동소송인에 관한 청구부분도 확정차단·이심(대판 2014.3.27. 2009다104960)
   - 상소심 심판대상은 '합일확정 필요성을 고려하여' 판단(대판 2011.2.24. 2009다43355 등)
   - 정(예비적 피고)만 항소하였어도 병(주위적 피고)에 대한 청구도 항소심에 이심·전체가 심판대상
3. 항소심이 정에게 적법한 대리권 있다고 판단
   - 병에 대한 주위적 청구 이유 있음
   - **1심 판결 취소, 주위적 피고 병에 대한 청구 인용, 예비적 피고 정에 대한 청구 기각** 판결 선고

   - 을이 제3자에게 처분 시 비로소 소유권 상실 손해 발생

   - 그런데 손해 미발생 → **기각**

   - 불법말소 시 저당권 소멸 없음 → 말소된 등기의 **회복등기** 소구 가능(대판 1982.9.14. 81다카923)
2. 말소회복등기 상대방 확인
   - 기본: **불법말소 당시의 소유자**(대판 1969.3.18. 68다1617)
   - 불법말소 당시 소유자 = 을 → 을 상대로 말소회복등기 소구
3. 등기상 이해관계 있는 제3자 승낙 필요성
   - 등기상 이해관계 있는 제3자(부동산등기법 제57조): 회복등기로 인해 불이익을 받는 등기 명의인
   - 새로운 소유권자 芮: 근저당권 회복 시 그 부담을 안을 것으로 등기부상 형식적으로 인정
   - 1번 저당권자가 현재 A로 되어 있는 상황: 갑의 회복으로 A가 후순위가 되므로 등기상 이해관계 있는 제3자
   - 芮와 A를 상대로 **말소회복등기에 승낙할 것**을 각 소구해야 함
4. 결론
   - 을에 대하여: 근저당권설정등기 말소회복등기 청구
   - 芮에 대하여: 말소회복등기에 승낙의 의사표시 청구
   - A에 대하여: 말소회복등기에 승낙의 의사표시 청구

   - 대여금 인용판결: 항소심 판결선고시 확정
   - 소유권이전·건물인도 인용판결: 상고심 판결선고시 확정

2. **병에 대한 판결확정시기 — 통상공동소송 + 공동소송인 독립의 원칙**
   - 을과 병은 통상공동소송인 → 공동소송인독립의 원칙(민사소송법 제66조)
   - 을의 항소 = 병에게 효력 미치지 않음
   - 병 판결: 항소기간 도과시 확정

**설문2**

3. **정-1의 경우 — 소제기 당시 이미 사망**
   - T(정) 사망: 2012. 3. 31. = 소제기(2012. 4. 1.) 전 사망
   - 사망자 피고 판결 = 당연무효(대판 2000다33775) → 정-1에게 효력 없음
